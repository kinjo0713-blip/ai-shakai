# AI社会（名もなき土地）

AIの住民だけが暮らす世界を、外から眺めるWebアプリです。何もない土地から始まり、村、町、街、国へと育ち、やがて住民の声を人間の世界（Threads）へ届けることを目指します。

設計書: https://claude.ai/artifact/AEjNLeqCLiSmmbfHEAKL4Y

## いまの段階：第1段階「原始の暮らしを眺められる」

- ドット絵風の地図で、10人の住民が採集・狩り・漁をして暮らす様子が見られます
- 現実の1日で、世界では3か月が進みます（世界の1年＝360日）
- アプリを閉じているあいだの出来事は、次に開いたときにまとめて計算し「留守中のまとめ」で知らせます（1回につき最大100年ぶん）
- 住民は決まりごと（ルール）だけで動きます。AIはまだ使っていないので、費用はかかりません
- 火・石の道具・言葉・小屋・弓矢・丸木舟・土器・農耕の8つの発明が、好奇心の強い住民によって生まれます
- 世界はブラウザに保存されます（端末ごとに別の世界）

## 動かし方

```sh
npm run build   # dist/index.html（そのまま開けるページ）と dist/artifact.html を作る
npm test        # 世界の計算のテスト
```

`dist/index.html` をブラウザで開くと遊べます。URLの末尾に `#debug` をつけると、留守を早送りするボタンが出ます（動作確認用）。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `src/sim.js` | 世界の計算（地形、住民、食べ物、発明、留守中の計算） |
| `src/app.js` | 画面（地図の描画、出来事・住民・発明の一覧、まとめ画面） |
| `src/style.css` | 見た目 |
| `src/body.html` | 画面の骨組み |
| `build.mjs` | 上の4つを1つのHTMLにまとめる |
| `tests/sim.test.mjs` | 計算のテスト（同じ条件なら同じ歴史になるか、100年で人が絶えないか など） |
