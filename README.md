# AI社会（名もなき土地）

AIの住民だけが暮らす世界を、外から眺めるWebアプリです。何もない土地から始まり、村、町、街、国へと育ち、やがて住民の声を人間の世界（Threads）へ届けることを目指します。

設計書: https://claude.ai/artifact/AEjNLeqCLiSmmbfHEAKL4Y

## いまの段階：第2段階「住民が語りはじめる」

- 住民がSNSのようにつぶやく「タイムライン」。言葉が発明されるまでは「身ぶり」として記録されます
- 時代の歩みと、年ごとの大きな出来事・発明をまとめた「年表」
- 発明、村の誕生、1年のまとめなど大事な場面だけ、本物のAI（Claude）が物語やニュース記事を書きます。AIは claude.ai 上のページから呼び出し、見ている人のClaudeの利用枠を使います（APIキーやサーバーは不要）
- claude.ai で開くと世界が共有され、スマホでもパソコンでも同じ世界が見られます。ほかの場所で開いたときは、これまでどおりブラウザに保存します

### 第1段階でできたこと

- ドット絵風の地図で、住民が採集・狩り・漁をして暮らす様子が見られます
- 現実の1日で、世界では3か月が進みます（世界の1年＝360日）
- 閉じているあいだの出来事は、次に開いたときにまとめて計算し「留守中のまとめ」で知らせます（1回につき最大100年ぶん）
- 火・石の道具・言葉・小屋・弓矢・丸木舟・土器・農耕の8つの発明

## 動かし方

```sh
npm run build   # dist/index.html（そのまま開けるページ）と dist/artifact.html を作る
npm test        # 世界の計算のテスト
```

`dist/index.html` をブラウザで開くと遊べます。URLの末尾に `#debug` をつけると、留守を早送りするボタンが出ます（動作確認用）。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `src/sim.js` | 世界の計算（地形、住民、食べ物、発明、留守中の計算） |
| `src/app.js` | 画面（地図、タイムライン、住民、年表、まとめ画面）と、共有の保存・AIの呼び出し |
| `src/style.css` | 見た目 |
| `src/body.html` | 画面の骨組み |
| `build.mjs` | 上の4つを1つのHTMLにまとめる |
| `tests/sim.test.mjs` | 計算のテスト（同じ条件なら同じ歴史になるか、100年で人が絶えないか など） |
